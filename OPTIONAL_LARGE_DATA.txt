完整变异库（Git LFS）
====================

路径：
  data/variants_index.db  (~543MB, Git LFS)

Render / Docker 构建时会随仓库检出。本地克隆请先：

  brew install git-lfs
  git lfs install
  git lfs pull

----------------
data/variants_summary_top.tsv 与 data/variants_alleles.tsv
已包含 top 位点的 Ref/Alt 碱基；variants_index.db 中对应行亦已写入。
